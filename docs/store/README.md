# N.I.N.A. catalog artwork

These are the presentation assets for the official QualitySessionMeter manifest.

- `featured.png`: QSM meter mark rendered from the same geometry used by the plugin icon.
- `nina-panel.png`: actual current QSM WPF monitoring DataTemplate rendered by the Windows visual harness.
- `web-dashboard.png`: actual current embedded Web Dashboard rendered in Chromium with deterministic telemetry and LIGHT-preview responses.

They are regenerated from the release source and are not hand-drawn UI mockups. Real N.I.N.A. host validation was completed before the first catalog release.
